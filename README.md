## ✨ Overview

This project recreates the immersive design style seen in premium  
Awwwards-level websites like **Zentry** — combining scroll-triggered  
animations, geometric clip-path transitions, 3D interactive elements,  
and polished visuals to create a stunning digital narrative.

Perfect for learning advanced animations, interaction design, and 
modern web layout techniques.

---

## 🚀 Tech Stack

- ⚛️ **React.js**
- 🎞️ **GSAP (GreenSock)**
- 🎨 **Tailwind CSS**
- 🌀 **Custom Fonts & High-Fidelity Visuals**

---

## 🔋 Features

### 🌀 Scroll-Triggered Animations  
Smooth, modern motion effects powered by GSAP ScrollTrigger.

### 🔷 Clip-Path Transitions  
Unique geometric masking animations for premium storytelling.

### 🧊 3D Hover Effects  
Interactive elements that respond dynamically to cursor movement.

### 🎬 Video-Driven Motion  
Video transitions used to enhance the narrative and elevate the aesthetic.

### 💎 Polished UI/UX  
High-end visual styling, seamless navigation, and buttery-smooth interactions.

### 📱 Fully Responsive  
Optimized for desktop, tablet, and mobile with pixel-perfect breakpoints.
